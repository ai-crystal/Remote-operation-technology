# 后记

开头那个朋友后来把网站跑起来了，也慢慢知道了自己在干什么。

有一次他问我，这些东西为什么不写在教程里。

我想了想，说，因为教程默认你已经知道它们了。

写教程的人踩过这些坑，踩完之后就忘了自己曾经不知道。他们写“把 host 改成 0.0.0.0”，是因为这个改动对他们来说像呼吸一样自然。他们不写“为什么”，因为他们也想不起来自己是什么时候学会的。

这本书想补的就是这一段。不是把知识再讲一遍，是把那些被省略掉的“为什么”捡回来。

网络这个东西有一个特点，它的知识是分层的，每一层都不难，难的是不知道自己在第几层。你以为是代码的问题，其实是端口。你以为是端口，其实是安全组。你以为是安全组，其实是 DNS 缓存。

分清楚层，问题就变小了。

书里没有公式，没有协议字段，没有算法推导。不是那些东西不重要，是它们不该是入口。入口应该是“为什么我打不开”，而不是“三次握手的序号怎么算”。

如果有一天你真的需要读一本讲 SSH 协议实现的书，你会发现自己看得懂它的目录了。那时候这本书的任务就完成了。

希望它能帮你少熬几个夜。

Dr. Dezeming
2026 年
