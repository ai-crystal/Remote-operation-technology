# 附录 B　入门术语表

**SSH**　Secure Shell，一套让你安全登录远端机器的协议，也是最常用的那个命令的名字。

**sshd**　服务器上等别人来连的那个程序，默认守在 22 端口。

**IP 地址**　机器在网络里的门牌号，写成四组数字，比如 `192.168.1.23`。

**私有地址**　只在一张内网里有意义的地址，`192.168.x.x`、`10.x.x.x` 都属于这一类。

**网段**　前几组数字相同的一组地址，同网段的设备可以直接通信。

**网关**　本网段里负责“出门”的那台设备，通常是路由器。

**端口**　一台机器上区分不同服务的编号，SSH 是 22，HTTPS 是 443。

**DNS**　把域名换成 IP 地址的系统，可以想成一本电话簿。

**NAT**　地址转换。家里的设备靠它共用一个公网地址出门，代价是外面连不进来。

**shell**　读你敲的命令、解释它、再交给系统执行的程序，比如 `bash`。

**进程**　程序跑起来之后的样子，有自己的编号、内存和身份。

**权限**　决定谁能读、写、执行一个文件的三组标志，`600` 表示只有自己可读写。

**公钥 / 私钥**　一对钥匙。公钥可以公开，装到服务器上；私钥自己留着，用来签名。

**指纹**　公钥算出来的短字符串，用来核对是不是同一把钥匙。

**known_hosts**　本机记录见过的服务器公钥的文件，用来发现变化。

**端口转发**　把远端的某个端口临时搬到本机，用 `ssh -L` 就能做。

**堡垒机**　集中管理远程访问的系统：统一入口、托管凭据、录制会话。

**对象存储**　用 HTTP 接口存取整个对象的存储服务，只有账号、桶、对象三层。

**桶 / 键**　桶是对象的容器，键是对象的名字，键里的斜杠不是目录。

**签名**　用密钥对请求算出的校验值，证明这个请求确实出自你手。

**监听**　程序在某个端口上等着别人来连。

**HTTP**　客户端和服务端说话用的协议，由方法、路径、头、体组成。

**状态码**　响应里的三位数字：2xx 成功，4xx 请求有问题，5xx 服务器出问题。

**任务队列**　把待处理的任务排队，由后台程序逐个取走执行。

**轮询 / SSE**　两种拿进度的方式：前者隔一会儿问一次，后者由服务端持续推送。

**会员**　身份、认证、授权、额度四件事合起来的一套东西。
