# 从一个人到一群人

一个人管三台机器，密钥放在自己电脑上就够了。三十个人管三百台机器，事情就变了样。

谁有哪台机器的权限，说不清。谁在什么时候登录过，查不到。同事离职三个月，他的公钥还躺在某台机器的 `authorized_keys` 里。生产库被误删，日志里只有一条 `root` 的操作记录，没人知道是谁。

这一篇讲的是组织层面的技术。堡垒机把分散的信任收拢到一个节点，用统一的认证、授权和审计来管理。VS Code 的远程开发则是另一个方向，它把开发环境搬到远端，让代码和数据待在一起，只把界面留在手边。

这两件事看起来不相关，底下的机制却是同一套。堡垒机的 SSH 网关在代理你的连接，VS Code 的远程扩展在复用你的 SSH 连接。理解了前两篇的连接原理，这一篇更多是在看它们怎么被组合、被限制、被记录。
