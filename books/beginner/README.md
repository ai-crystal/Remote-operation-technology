# 远程之门 · 入门

> 不背命令，先弄懂它在干什么

从一条 `ssh` 登录讲起，用十章把远程操作的整条链路想通：数据怎么走、地址和端口是什么、连不上怎么查、登录后发生了什么、钥匙怎么用、内网服务怎么搬到手边、堡垒机与对象存储是什么、怎么把程序做成别人能用的服务。

**没有公式，不要求会写代码，每章结尾三句话收尾。**

## 这一册适合谁

- 第一次接触服务器、SSH、Linux 的人
- 会用几条命令，但说不清背后在发生什么的人
- 想在做项目之前，先把概念理顺的人
