# 附录 B　人话术语表

按拼音排序。定义尽量短，能一句话说清就不写两句。

| 术语 | 人话 |
| --- | --- |
| API | 程序之间说话的方式，你给它一个请求，它给你一个结果 |
| CIDR | 描述一段地址范围的写法，`10.0.0.0/8` 表示前十位固定，后面随便 |
| CNAME | DNS 里的一条别名记录，指向另一个名字而不是地址 |
| DNS | 把域名换成 IP 的黄页 |
| Docker | 把程序和它需要的环境打包在一起，换台机器也能一样跑 |
| endpoint | 接口地址，比如 `cos.ap-guangzhou.myqcloud.com` |
| firewall | 防火墙，按规则决定哪些包能进出 |
| fork | 进程复制自己，Linux 起新程序的常见方式 |
| gateway | 网关，本网段通往外面的那扇门 |
| GPU | 显卡，现在主要用来算矩阵 |
| hosts | 本机的一本小黄页，优先级比 DNS 高 |
| HTTP | 网页用的说话格式，请求加响应，一堆文本 |
| HTTPS | HTTP 加了一层加密和身份证明 |
| ICMP | ping 用的协议，跟 TCP 无关 |
| IP | 门牌号，标明一台机器在网络里的位置 |
| IPv4 / IPv6 | 两代地址格式，后者长得多，数量近乎无限 |
| journalctl | 看系统和服务日志的命令 |
| key | 对象存储里对象的名字，不是目录 |
| known_hosts | 记录你见过的服务器指纹的本子 |
| localhost | 指这台机器自己，等于 `127.0.0.1` |
| MAC 地址 | 网卡出厂时的硬件编号，同一个局域网内用 |
| MTU | 一个包最大能装多少，常见 1500 字节 |
| NAT | 地址转换，小区门卫帮你代收代发 |
| nginx | 读作 engine-x，常用来做反向代理和静态文件的服务器软件 |
| nohup | 让程序忽略挂断信号，关掉终端也不死 |
| OOM | 内存不够，系统把进程杀掉 |
| PATH | 系统找命令时按顺序查的那几个目录 |
| PID | 进程编号 |
| port | 端口，机器上的房间号 |
| proxy | 代理，替你去访问别处 |
| 反向代理 | 服务器那边的代理，替后面的服务接待外面的人 |
| publickey | 公钥认证，用锁和钥匙代替密码 |
| root | Linux 里的管理员账号 |
| rsync | 同步文件的工具，能续传、只传变化的部分 |
| scp | 走 SSH 传文件，简单但没有续传 |
| SHELL | 你在终端里敲命令时跟你对话的那个程序 |
| SOCKS | 一种代理协议，浏览器可以配它 |
| SSH | 加密的远程终端，也能传文件和开隧道 |
| sshd | SSH 的服务端，守在 22 端口 |
| sudo | 以管理员身份执行这一条命令 |
| systemd | 管服务的系统组件，负责启动、重启、开机自启 |
| TCP | 可靠的传输，像挂号信，有确认有重发 |
| TLS | HTTPS 里那层加密和证书协商 |
| TOFU | 第一次见面就信任，SSH 记录指纹的机制 |
| TTL | 一条 DNS 记录能被缓存多久，单位秒 |
| UDP | 不可靠的传输，像发传单，快但可能丢 |
| VPN | 虚拟专用网络，连上就像坐进了公司的网 |
| WebSocket | 一条一直开着的双向连接，适合实时推送 |
| 对象存储 | 云上的仓库，存文件，按量收费，用 URL 取 |
| 桶 | 对象存储里的顶层容器，名字全局唯一 |
| 堡垒机 | 统一入口加操作录像的运维系统 |
| 跳板机 | 一台用来中转的服务器，先进它再进别的 |
| 隧道 | 把一种流量塞进另一条已建立的连接里运输 |
| 回环地址 | `127.0.0.1`，数据不出网卡，只在本机转 |
| 安全组 | 云平台在机器外面加的一层防火墙 |
| 带宽 | 每秒能过多少数据，单位 Mbps，除以八才是 MB/s |
| 快照 | 磁盘在某一刻的完整拷贝，用来后悔 |
| 监听 | 程序在某个端口上等着别人来连 |
| 私钥 | 钥匙，绝不能给别人 |
| 公钥 | 锁，可以随便贴 |
| 指纹 | 公钥算出来的一个短字符串，用来核对身份 |
| 网段 | 前几位相同的一组地址，同一个网段能直接互通 |
| 虚拟机 | 物理机切出来的一份，有自己的系统 |
| 内网 | 只在局部可达的网络，外面看不见 |
| 公网 IP | 互联网上能被找到的地址 |
| 端口转发 | 把到一个端口的连接转给另一个地址的端口 |
| 令牌 | token，一段证明身份的字符串，通常有时效 |
| 灰度 | 先让一小部分用户用新版本 |
| 幂等 | 同一个请求做一次和做十次结果一样 |
| 限流 | 限制单位时间内的请求数 |
| 熔断 | 下游一直失败时先别再打它，避免拖垮自己 |
